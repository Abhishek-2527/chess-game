# ♟ JavaScript Chess Game

A fully interactive two-player chess game built using HTML, CSS and JavaScript.

## 🚀 Features

- Complete 8×8 chess board
- White and Black pieces
- Legal chess moves
- Piece movement validation
- Capturing
- Check detection
- Checkmate detection
- Stalemate detection
- Castling
- En passant
- Pawn promotion
- Undo move
- New game
- Move history
- Responsive design
- Keyboard-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Chess.js

## 📁 Project Structure

chess-game/
│
├── index.html
├── style.css
├── script.js
└── README.md

## ▶️ How to Run

1. Clone the repository.
2. Open the project in VS Code.
3. Open `index.html` using Live Server.
4. Start playing.
